# multibody: API reference

Generated from the comments of the headers under `include/mbd/` (plan task
H.5). How the engine works, the conventions it follows and how to use it are
in the documents of the repository:

- `docs/help/README.md`: the help, with the how-to guides, the
  troubleshooting guide and the message catalogue;
- `docs/kernel.md`: the multibody kernel;
- `docs/conventions.md`: units, frames, signs and naming.

The namespaces:

- `mbd`: core types, rigid bodies, force elements, vehicles and analyses;
- `mbd::kernel`: the multibody kernel (models, algorithms, constraints, the
  constrained solve, the simulator, assembly, statics, linearisation, events,
  diagnostics).

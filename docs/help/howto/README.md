# How-to guides

Each page shows one task with an example taken from `tests/examples/`, where
it is compiled and run as a test; `tests/core/test_howto_examples.cpp` checks
that the code on each page is the code that runs (task H.6).

| To do this | Page |
|---|---|
| Add springs, dampers, stops, joint friction | [forces](forces.md) |
| Drive a joint or a point; a mechanism's motion ratios | [motion](motion.md) |
| Record forces, reactions and energies | [outputs](outputs.md) |
| Start from values that do not satisfy the constraints | [assembly](assembly.md) |
| Find a resting state | [statics](statics.md) |
| Natural frequencies, damping and mode shapes | [modes](modes.md) |
| Contact with the ground, with friction | [contact](contact.md) |
| Stop at, or act on, an event | [events](events.md) |
| Find out what went wrong | [trace](trace.md) |
